## Proyectos

### Narrativa de Datos para la Transformación Digital - TechCorp

Proyecto desarrollado para analizar el proceso de transformación digital de una empresa ficticia.

En este trabajo se aplicaron:

- Análisis de indicadores
- Identificación de insights
- Visualización de datos
- Narrativa de datos
- Elaboración de recomendaciones
- Presentación de resultados

Este proyecto me permitió practicar cómo transformar datos en información útil para apoyar la toma de decisiones.
