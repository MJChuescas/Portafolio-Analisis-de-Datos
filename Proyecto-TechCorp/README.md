Proyecto TechCorp - Narrativa de Datos para la Transformación Digital

Este proyecto fue desarrollado durante mi formación en Análisis de Datos.

El objetivo fue analizar los resultados de una empresa ficticia llamada TechCorp, que se encontraba en un proceso de transformación digital.

## Habilidades aplicadas

- Análisis de indicadores
- Identificación de insights
- Visualización de datos
- Narrativa de datos
- Elaboración de recomendaciones
- Presentación de resultados

## Archivos del proyecto

- Análisis y definición de la narrativa
- Presentación de resultados
- Storyboard y script ejecutivo

Este trabajo me permitió practicar cómo comunicar resultados de manera clara y apoyar la toma de decisiones utilizando datos.
